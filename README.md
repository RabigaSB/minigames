# minigames

It's a website to demonstrate usage of Typescript as SPA tool for RS School Short-track course.

Task: https://github.com/rolling-scopes-school/qualifying-stage/blob/main/tasks/minigames/README.md

The MiniGames app session is stored under the localStorage key
`minigames:minigames-app-734e1:app-session`. It contains only the profile data needed by
the client and expires five minutes after authentication.
